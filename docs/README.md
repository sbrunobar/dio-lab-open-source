## 📌 Sobre o Projeto

Este repositório foi criado para fins **didáticos**, dentro do curso **Contribuindo em um Projeto Open Source no GitHub** da [Digital Innovation One](https://www.dio.me/).

O objetivo é permitir que você pratique o processo de contribuição em projetos Open Source no GitHub, aprendendo a:

* Fazer um **fork** do repositório;
* Criar alterações ou melhorias;
* Subir suas mudanças;
* Abrir um **Pull Request (PR)** para o repositório principal.

> 🔎 **Dica:** Markdown é a linguagem recomendada para documentações. Já a correção de bugs ou implementação de funcionalidades depende da linguagem usada no código do projeto.

## ✅ Como Contribuir

1. Faça um **fork** deste repositório.
2. Crie uma nova branch para sua alteração:

   ```bash
   git checkout -b minha-contribuicao
   ```
3. Realize as modificações desejadas (ex: documentação, README, correção de erros).
4. Salve e faça o commit:

   ```bash
   git commit -m "Melhoria na documentação"
   ```
5. Faça o push para o seu fork:

   ```bash
   git push origin minha-contribuicao
   ```
6. Abra um **Pull Request** no repositório principal.
